about=Merge any number of GeoPackages – with everything stored in them – into a new GeoPackage.
    - Copies vector and attribute layers (with field aliases, comments and value domains), raster tiles, DEMs (gridded coverages), vector tiles, plain tables, views, metadata, related-table relations, QGIS layer styles and QGIS projects.
    - QGIS projects stored in the files are redirected to the merged file, including renamed layers.
    - Set the merge order by drag & drop or the up/down buttons.
    - Layers with the same name (compared case-insensitively) can be:
      * kept and renamed to <gpkg name>_<layer name>,
      * overwritten – the file that comes later in the order wins,
      * appended into one layer – geometry type, CRS and fields are checked first; if they do not match nothing is written and you can change the selection.
    - A preview shows the result of every layer before merging.
    - QGIS layer styles stored in the files (layer_styles) follow their layers.
    - The user interface follows the QGIS language setting: English, Traditional Chinese, Simplified Chinese, Japanese, Korean, German, French, Spanish.
    Works with QGIS 3.22+ and QGIS 4 (Qt6).
    Uses only GDAL/OGR which ships with QGIS; no extra Python packages needed.
